# 地方競馬15場 ３連単万馬券（配当10,000円以上）の競馬場別特徴

- 対象: **2023年〜2026年8月**、計 **56,233レース**
  - 人気・騎手・頭数・レース番号: 2023〜2026年の全データ
  - 馬場状態・脚質・距離・格付け: レース一覧がある **2024年〜2026年8月**（約40,000レース）
- 脚質の判定: コーナー通過順から算出（最初のコーナーで先頭＝逃げ、最終コーナーで前35%以内＝先行、70%以内＝差し、それより後ろ＝追込）。ばんえいはコーナーがないため対象外
- 「穴馬」は 6番人気以下とした
- 騎手の指標
  - **穴期待比**: 6番人気以下に騎乗したときの3着内率を、その場の平均（約9〜15%）で割った値。対象は6番人気以下への騎乗が150回以上の騎手
  - **穴複勝回収率／穴単勝回収率**: 6番人気以下の馬すべてに100円ずつ賭けた場合の回収率
- 再現手順: `python3 analysis/manbaken_analysis.py <dataディレクトリ>` を実行（集計表は `analysis/out/*.csv`）

**4年分で確認できた共通の傾向**
1. **頭数の影響が最も大きい。** 8頭以下の万馬券率は22〜31%（帯広のみ42%）、11〜12頭で49〜64%、13頭以上で50〜75%。
2. **万馬券でも、半分強のレースで1番人気が3着内に入っている。** 万馬券レースで1番人気が着外になる率は、全場で42〜48%に収まる。
3. **穴馬（6番人気以下）は3着に来やすい。** 万馬券で3着内に入った穴馬のうち41〜46%が3着、1着は約20〜24%。
4. **万馬券になるレースでは前残りが崩れる。** 4角3番手以内の馬が3着内を占める割合は、全場で6〜12ポイント下がる。差しの勝ちは1.2〜2.2倍に、追込の勝ちは2〜4倍に増える。
5. **1番人気が凡走したときは、差し・追込のケースが5.5〜7割。** 人気の差し・追込馬が届かないことが、万馬券の主な原因になっている。

> **前回（2023年＋2026年のみ）からの修正点**: 「川崎は湿った馬場で荒れる」「名古屋は稍重で大きく荒れる」は、2024・2025年を加えると差が小さくなった（川崎は良55.5%・不良52.1%でほぼ差なし）。一方、「高知・川崎は9R以降に荒れる」「帯広は1〜4Rが荒れる」「船橋は前が止まる」「浦和は先行の穴」は、4年とも同じ傾向で、再現性が高い。

## 2. 競馬場別の特徴

### 帯広（ばんえい）― 万馬券率1位（60.5%）
- **人気との乖離**: 1番人気の勝率34.8%・複勝率68.0%は、いずれも全場で最低。穴馬の3着内率15.1%は全場で最高。万馬券時の勝ち馬は4〜6番人気が33.9%。
- **馬場（水分量）**: 1.4%以下の重い馬場では56.2%。1.5%以上になると62〜63%に上がり、**砂が乾いているほど堅い**。
- **レース番号**: 1〜4Rが66.8%で、4年とも65〜67%と安定している。重賞は35.2%、準重賞は29.4%と、上級戦はかなり堅い。
- **騎手**: 万馬券を穴馬で演出した回数は 赤塚健(269) と 金田利(254) が多い。金田利は穴期待比1.27倍。**林康文は穴期待比1.47倍で、穴複勝回収率103%・穴単勝回収率128%**。一方、西将太（36.7%）・中原蓮（38.6%）は1番人気で着外になる率が高い。

### 大井 ― 高額配当が最も多い（10万円超12.9%）
- **年次の変化**: 61.7% → 59.3% → 56.4% → 54.2% と毎年下がっている。
- **馬場**: 不良62.9%。良・稍重・重は56〜57%。
- **頭数・時間帯**: 13頭以上で69.2%。9R以降は61.5%。
- **脚質・展開**: 4角3番手以内の3着内占有率は、通常時63.5%から万馬券時53.5%に下がる。追込の勝ちは1.2%から4.2%へ増える。穴馬の50%が差し・追込。
- **騎手**: 達城龍（万馬券演出148回、1.57倍）。本田重は1.63倍で、穴複勝回収率97%・穴単勝回収率130%。上位人気の騎乗が多い 矢野貴（2.0倍）と笹川翼（1.87倍）も、穴馬に乗ったときによく走る。吉井章は1番人気での着外率が34.2%。

### 川崎 ― 最終盤に荒れる
- **レース番号**: 9R以降が68.3%（2024〜2026年は毎年67〜70%）、1〜4Rは45.3%。
- **格付け・距離**: 特別戦66.3%、1800m以上64.3%。
- **馬場**: 良55.5%・稍重54.8%・重56.8%・不良52.1%で、**差はほとんどない**。
- **脚質**: 逃げの勝ちが通常時41.9%から万馬券時30.0%に下がる。
- **騎手**: 新原周（演出83回、1.30倍）、櫻井光（1.40倍、穴複勝回収率90%）、矢野貴（1.79倍）、張田昂（1.66倍）。櫻井光は1番人気での着外率が46.5%と高い。

### 浦和 ― 先行の穴で荒れる
- **年次の変化**: 53.8% → 58.6% と上がり続けている。
- **脚質**: 逃げ馬の3着内率は通常時72.2%で全場最高。万馬券時でも4角3番手以内の3着内占有率は73.9%と高い。**穴馬の52.3%が先行馬**（全場最高）で、追込の穴はわずか2%。
- **条件**: 9R以降63.3%。特別・重賞はいずれも63%。1800m以上66.7%。
- **騎手**: 和田譲（1.67倍）、佐野遥（1.63倍）、張田昂（1.56倍）。中山遥は穴単勝回収率176%、木間龍は穴複勝回収率100%。見越彬は1番人気での着外率が38.2%。

### 名古屋 ― 勝ち馬は堅く、2・3着が荒れる
- **人気**: 万馬券時の勝ち馬は1〜3番人気が58.0%。穴馬の45%が先行馬で、人気薄の先行馬が2・3着に粘る形。
- **馬場**: 良51.6%に対し、稍重・重・不良は55〜56%。湿るとやや荒れる。
- **距離**: 1200m以下44.1%に対し、1500m超は55〜56%。
- **騎手**: 大畑慧（演出171回）、細川智（167回）、丹羽克（152回、1.28倍）、塚本征（1.35倍）、渡邊竜（1.58倍、穴複勝回収率88%）。浅野皓は1番人気での着外率が36.2%。

### 盛岡 ― 差しの穴で荒れる
- **馬場**: 良54.2%が最も高く、雨の影響は小さい。
- **レース番号**: 5〜8Rは55.3%、9R以降は56.9%。1〜4Rは45.1%。
- **脚質**: 穴馬の51%が差し・追込。万馬券時は差しの勝ちが20.3%、追込の勝ちが3.7%。
- **騎手**: **坂口裕は1.59倍で、穴複勝回収率120%**。村上忍（1.46倍）、高橋悠（1.29倍）。小林凌は1番人気での着外率が33.3%。

### 船橋 ― 前が止まって荒れる
- **展開**: 4角3番手以内の3着内占有率は、通常時64.5%・万馬券時52.5%で、いずれも全場最低クラス。万馬券時の追込の勝ちは6.2%で全場最高。穴馬の57%が差し・追込（追込だけで18.5%は全場最高）。
- **条件**: 1600m前後（1501〜1800m）で59.7%。重賞59.5%。
- **年次の変化**: 2026年は55.6%に上がった。9R以降は68%。
- **騎手**: 澤田龍（1.49倍、穴複勝回収率90%）、岡村健（1.36倍）、篠谷葵（1.34倍、穴複勝回収率92%）。野畑凌は1番人気での着外率が35.9%。

### 水沢 ― 逃げが強い場だが、不良と最終盤は荒れる
- **脚質**: 逃げ馬の3着内率は通常時66.1%。穴馬の46%が先行馬。
- **馬場**: 不良53.7%に対し、良48.5%・稍重47.3%。
- **時間帯・距離**: 9R以降55.0%、1〜4R42.0%。1200m以下は40.9%と堅い。
- **騎手**: 村上忍（1.60倍、穴複勝回収率90%）、山本政（1.43倍）、山本紀（穴複勝回収率96%。ただし1番人気での着外率も38%）。佐々志は穴期待比0.58倍と低い。

### 高知 ― 最終盤で荒れる傾向が最も強い
- **レース番号**: **9R以降が61.9%（4年とも58〜67%）**、1〜8Rは37〜39%。ナイター後半は別物と考えてよい。
- **馬場**: 良・稍重・重・不良とも44〜45%で、影響はない。
- **距離**: 1200m以下は25.0%と堅い。
- **騎手**: 多田誠（1.51倍、穴単勝回収率114%）、永森大（1.44倍、穴単勝回収率140%）、井上瑛（1.33倍）、山崎雅（演出123回）。上田将は1番人気での着外率が33.3%。

### 佐賀 ― 年々堅くなっている
- **年次の変化**: 50.8% → 43.4% → 42.8% → 38.3% と、15場で唯一一貫して下がっている。
- **脚質**: 通常時の勝ち馬は逃げ・先行が95%。穴馬の47%が先行馬で、差し・追込の穴は少ない。
- **馬場・距離**: 稍重45.3%に対し、良40.2%。1200m以下35.2%に対し、1500m超45.0%。
- **騎手**: 石川慎（1.66倍）、飛田愛（1.40倍）、竹吉徹（演出119回、1.24倍）、川島拓（演出137回）。中山蓮は1番人気での着外率31.4%。

### 園田 ― 中位人気の決着が多い
- **人気**: 万馬券時の勝ち馬は4〜6番人気が34.3%。7番人気以下の勝ちは9.7%と少ない。**大波乱より中穴が多い。**
- **馬場**: 不良51.3%に対し、良43.0%（不良は199レース）。
- **距離**: 1200m以下45.8%に対し、1800m超35.2%。**短距離のほうが荒れる**珍しい場。
- **騎手**: 廣瀬航（演出112回、1.32倍）。小牧太は2.07倍（穴騎乗は183回と少ない）。吉村智（1.53倍）、下原理（1.32倍）、大山龍（穴複勝回収率83%）。

### 姫路 ― 2026年に荒れ傾向
- **年次の変化**: 2023〜2025年は約41%だったが、2026年は49.3%に上がった。
- **レース番号**: 1〜4Rが48.3%で、9R以降の41.1%より荒れる。
- **距離**: 1800m以上は20.0%と非常に堅い。
- **騎手**: 廣瀬航（1.70倍、穴単勝回収率127%）、下原理（1.51倍）。

### 門別 ― 湿った馬場と差しで荒れる
- **馬場**: 重41.6%・不良41.9%に対し、良38.2%。
- **脚質**: 万馬券時は差しの勝ちが14.4%から24.0%に増える。穴馬の55%が差し・追込。
- **距離・頭数**: 1800m以上は17.6%と非常に堅い。13頭以上でも50%にとどまる。
- **騎手**: 宮崎光（1.74倍）、服部茂（1.66倍）、石川倭（1.64倍）、小野楓（演出98回）。松井伸は穴騎乗が多いが、穴期待比は0.79倍と低い。

### 笠松 ― 不良と長距離で荒れる
- **人気**: 10万円超の率4.2%は全場最低。7番人気以下の勝ちは8.3%。
- **馬場**: 不良43.4%に対し、ほかは34〜39%。
- **距離・格付け**: 1200m以下28.6%に対し、1800m以上46.9%。重賞57.1%。
- **展開**: 1番人気が凡走したときの26%が追込馬（全場最高）。
- **騎手**: 望月洵（1.50倍）、丸野勝（1.46倍）、筒井勇（穴単勝回収率150%）、東川慎（演出110回、穴単勝回収率112%）、井口裕（穴複勝回収率118%）。森島貴は1番人気での着外率31.1%。

### 金沢 ― 最も堅い（1番人気の複勝率80.8%）
- **人気**: 1番人気の勝率50.2%・複勝率80.8%は、いずれも全場最高。
- **馬場**: 36〜40%で、ほとんど差がない。
- **荒れるパターン**: 9R以降が44.1%。穴馬の54%が差し・追込。
- **騎手**: 中島龍（1.57倍）。松戸政は1.39倍・演出99回・穴単勝回収率120%で、1番人気での着外率14.3%と人気馬でも堅い。青柳正（1.33倍）。甲賀弘は1番人気での着外率が38.0%。
