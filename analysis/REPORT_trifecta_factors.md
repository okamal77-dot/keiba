# ３連単の的中馬（1〜3着）と各要因の関連性 ― 地方15場・2023〜2025年

- 対象: 2023〜2025年の地方競馬 **45,869レース・460,393頭**（5頭立て以上、払戻データのあるレース。取消・除外・中止の馬は除く）
- 「的中馬」は、３連単を構成する1着・2着・3着の馬（＝3着内の馬）とした。配当は見ていない
- 再現手順: `python3 analysis/trifecta_factors.py <dataディレクトリ>`（集計表は `analysis/out/tf_*.csv`）

## 分析の方法 ― 人気の影響を差し引き、3年とも同じかを確かめる

どの要因も人気と強く結びついています（例: 前走で速い時計を出した馬は人気になる）。そのため、単純な3着内率で比べると、ほとんどが「人気の言い換え」になります。

そこで、各馬について「**同じ年・同じ競馬場・同じ人気・同じ頭数帯**の馬の平均3着内率」を期待値とし、要因のカテゴリごとに次の比を計算しました。

> **A/E ＝ 実際の3着内数 ÷ 人気から見た期待3着内数**
> 1.10 なら「人気から見込まれるより1割多く馬券に絡んだ」、0.90 なら「1割少なかった」。

表中の **＊** は「2023・2024・2025年の**3年とも**同じ向き（3年とも1超、または3年とも1未満）」だったことを示します。＊のない数値は年によって向きが変わるため、偶然の可能性があります。

要因の定義

| 要因 | 定義 |
|---|---|
| 走破タイム（近走指数） | 各走のタイムを「競馬場×距離×馬場状態」ごとに偏差値化（z値）。直近3走のベストをレース内で順位付け |
| 持ち時計 | データにある「最高タイム」をレース内で順位付け |
| 上がり3F | ①そのレース内の上がり順位（結果）、②前走の上がり順位（事前情報） |
| 脚質 | コーナー通過順から判定（最初のコーナーで先頭＝逃げ、最終コーナーで前35%以内＝先行、70%以内＝差し、それより後ろ＝追込）。①そのレースの脚質（結果）、②前走の脚質（事前情報）。ばんえいは対象外 |
| 体重変化 | 馬体重増減 |
| 騎手との相性 | 「騎手成績」列（＝この騎手でこの馬に乗ったときの成績）。3戦以上で3着内率50%以上を「好相性」、20%以下を「低相性」、0戦を「初コンビ」とした。あわせて、前走からの乗り替わりかどうか |
| 天候・馬場 | レース一覧の天候・馬場状態。ばんえいは馬場水分（%）を3区分 |
| 転厩・遠征 | 前走から調教師の所属地区が変わった馬＝「他地区から転入初戦」、所属地区は同じで調教師が変わった馬＝「同地区内の転厩初戦」、調教師の所属がその競馬場の地区と違う馬＝「遠征馬」 |

## 結論（全体）

1. **最も強く関係するのは人気。** 他の要因は、人気を差し引くと影響が±5〜15%程度に小さくなる。ただし、以下は**3年とも同じ向きに出ており、再現性がある**。
2. **走破タイム（近3走ベスト指数）は、人気を差し引いても残る最大の要因。** レース内1〜2位はA/E 1.05、6位以下は0.91（3年とも0.90〜0.92）。**15場すべてで、6位以下は3年とも人気以下**だった。
3. **前走の上がり3Fも効く**（前走1位1.05、6位以下0.96。3年ともほぼ同じ値）。ただし、走破タイムより影響は小さい。
4. **前走の脚質**: 前走「先行」「差し」は1.03、「逃げ」は0.97、「追込」は0.93。**前走で逃げた馬は人気になりすぎ、前走で追い込んだ馬は人気でも来ない**。3年とも同じ向き。
5. **体重**: −4〜−9kgが最良（1.03）。**+10kg以上（0.96）、+4〜+9kg（0.97）、−10kg以下（0.95）は割引**。3年とも同じ向き。
6. **騎手**: **低相性コンビは0.92**で、3年とも0.92〜0.93。好相性は1.03、初コンビは0.98。乗り替わりかどうかの差は小さい（0.99と1.01）。
7. **転厩・遠征は場によって逆になる。** 他地区からの転入初戦は、**園田0.80・名古屋0.86・高知0.88・門別0.87**で人気より走らない。一方、**笠松は1.08**。遠征馬は**笠松・浦和・佐賀・金沢・盛岡で1.09〜1.13**、大井・船橋・高知では割引。
8. **天候・馬場**は、3年とも同じ向きのものが少ない。再現性があるのは「**帯広は乾いた重い馬場（水分1.4%以下）で堅い**」「**名古屋・船橋は不良で荒れる**」程度。脚質への影響では、多くの場で不良馬場ほど3着内に占める逃げ・先行の割合が上がる。

## 注意点

- 3年とも同じ向きでも、効果は±5〜15%程度。**人気の影響を覆すほどではなく、「人気が同じ馬の中でどれを選ぶか」の判断材料**として使うのが妥当です。
- 「前走」「近3走」「乗り替わり」「転入」は、データ期間（2023年1月〜2025年12月）内の出走だけで判定しています。2023年初めのレースや、期間中に初めて出てきた馬は「データなし」になります。
- **2023年の船橋は、全レースの馬場状態が「良」で記録されていた**ため、馬場の分析とその年の船橋の走破タイム指数からは除きました。
- 「騎手成績」列は、その騎手がその馬に乗ったときの通算成績として扱いました（全成績との整合から判断）。
- レース中の上がり順位・脚質は**結果**であり、事前には分かりません。予想に使えるのは「前走の上がり・脚質」や「近走指数」の方です。
- 走破タイム指数は「競馬場×距離×馬場状態」で偏差値化した簡易的なもので、クラス差や斤量は補正していません。
