# ３連単の的中馬（1〜3着）と各要因の関連性 ― 地方15場・2025年

- 対象: 2025年の地方競馬 **15,062レース・152,851頭**（5頭立て以上、払戻データのあるレース。取消・除外・中止の馬は除く）
- 「的中馬」は、３連単を構成する1着・2着・3着の馬（＝3着内の馬）とした。配当は見ていない
- 再現手順: `python3 analysis/trifecta_factors.py <dataディレクトリ>`（集計表は `analysis/out/tf_*.csv`）

## 分析の方法 ― 人気の影響を差し引いて比べる

どの要因も人気と強く結びついています（例: 前走で速い時計を出した馬は人気になる）。そのため、単純な3着内率で比べると、ほとんどが「人気の言い換え」になります。

そこで、各馬について「**同じ競馬場・同じ人気・同じ頭数帯**の馬の平均3着内率」を期待値とし、要因のカテゴリごとに次の比を計算しました。

> **A/E ＝ 実際の3着内数 ÷ 人気から見た期待3着内数**
> 1.10 なら「人気から見込まれるより1割多く馬券に絡んだ」、0.90 なら「1割少なかった」。
> |z| ≧ 2.5 を「偶然とは考えにくい差」とした。

要因の定義

| 要因 | 定義 |
|---|---|
| 走破タイム（近走指数） | 各走のタイムを「競馬場×距離×馬場状態」ごとに偏差値化（z値）。直近3走のベストをレース内で順位付け（2025年内の過去走のみ） |
| 持ち時計 | データにある「最高タイム」をレース内で順位付け |
| 上がり3F | ①そのレース内の上がり順位（結果）、②前走の上がり順位（事前情報） |
| 脚質 | コーナー通過順から判定（最初のコーナーで先頭＝逃げ、最終コーナーで前35%以内＝先行、70%以内＝差し、それより後ろ＝追込）。①そのレースの脚質（結果）、②前走の脚質（事前情報）。ばんえいは対象外 |
| 体重変化 | 馬体重増減 |
| 騎手との相性 | 「騎手成績」列（＝この騎手でこの馬に乗ったときの成績）。3戦以上で3着内率50%以上を「好相性」、20%以下を「低相性」、0戦を「初コンビ」とした。あわせて、前走からの乗り替わりかどうか |
| 天候・馬場 | レース一覧の天候・馬場状態。ばんえいは馬場水分（%）を3区分 |
| 転厩・遠征 | 前走から調教師の所属地区が変わった馬＝「他地区から転入初戦」、所属地区は同じで調教師が変わった馬＝「同地区内の転厩初戦」、調教師の所属がその競馬場の地区と違う馬＝「遠征馬」 |

## 結論（全体）

1. **最も強く関係するのは人気。** 他の要因は、人気を差し引くと影響が±5〜15%程度に小さくなる。その中で一貫して効くのは「近走の走破タイム」「騎手との相性（悪い方）」「体重の大幅増」「前走の脚質（追込は割引）」の4つ。
2. **走破タイム（近3走ベスト指数）は、人気を差し引いても残る最大の要因。** 指数上位1〜2位はA/E 1.05〜1.06、6位以下は0.91（z＝−11）。15場すべてで「6位以下は人気より走らない」。
3. **レースの中では、上がり3Fと先行力が着順を決めている**（結果から見た特徴）。勝ち馬の76〜89%が上がり3位以内。先行馬は人気を差し引いても期待の1.3〜1.7倍、追込馬は0.1〜0.5倍。
4. **ただし、前走の脚質で見ると逆になる。** 前走「差し」はA/E 1.04、前走「逃げ」は0.97。前走で逃げた馬は人気になりすぎる傾向があり、前走追込は0.93と割引。
5. **騎手は「相性が良い」より「相性が悪い」方が効く。** 低相性コンビはA/E 0.92（高知0.76、金沢0.74、佐賀0.84）。好相性は1.04。乗り替わりかどうかは、ほぼ関係しない（0.99と1.01）。
6. **体重は「−4〜−9kg」が最も良く（A/E 1.04）、「+10kg以上」「−10kg以下」はどちらも0.95。**
7. **転入初戦は場によって大きく違う。** 園田（0.67）・門別（0.71）では明確に走らない。他の場ではほぼ人気どおり。
8. **天候・馬場の影響は、場ごとの差が大きく、サンプルも少ない。** 共通の傾向は「馬場が渋るほど先行が有利（多くの場で不良・重の先行A/Eが良を上回る）」程度。不良馬場では、大井・川崎・笠松・門別で1番人気の3着内率が62〜67%に落ちる（良馬場では74〜80%）。

## 注意点

- **1年分（2025年）のみ**の分析です。場ごと・カテゴリごとのサンプルが数十〜数百のものは、偶然の可能性があります（以前の万馬券分析では、2年分で見えた馬場の傾向が4年分では消えた例がありました）。

- レース中の上がり順位・脚質は**結果**であり、事前には分かりません。予想に使えるのは「前走の上がり・脚質」や「近走指数」の方です。
