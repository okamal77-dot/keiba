# ３連単の的中馬（1〜3着）と各要因の関連性 ― 地方15場・2023年〜2026年9月

- 対象: 2023年1月〜2026年9月の地方競馬 **57,232レース・575,248頭**（5頭立て以上、払戻データのあるレース。取消・除外・中止の馬は除く）。2026年は1〜9月
- 「的中馬」は、３連単を構成する1着・2着・3着の馬（＝3着内の馬）とした。第1〜9節は配当を見ていない。第10〜11節で、穴馬選びに使ったときの回収率（単勝・複勝・３連単）を検証した
- 2026年9月分は確定オッズもあるため、**人気順位の代わりにオッズで補正した検証**も行った（第9節）
- 再現手順: `python3 analysis/trifecta_factors.py <dataディレクトリ>`（集計表は `analysis/out/tf_*.csv`）、`python3 analysis/longshot_payout.py <dataディレクトリ>`（穴馬の回収率、`analysis/out/ls_*.csv`）、`python3 analysis/class_payout.py <dataディレクトリ>`（クラス別の回収率、`analysis/out/cls_*.csv`）、`python3 analysis/ability_index.py <dataディレクトリ>`（能力値、`analysis/out/ab_*.csv`）

## 分析の方法 ― 人気の影響を差し引き、4年とも同じかを確かめる

どの要因も人気と強く結びついています（例: 前走で速い時計を出した馬は人気になる）。そのため、単純な3着内率で比べると、ほとんどが「人気の言い換え」になります。

そこで、各馬について「**同じ年・同じ競馬場・同じ人気・同じ頭数帯**の馬の平均3着内率」を期待値とし、要因のカテゴリごとに次の比を計算しました。

> **A/E ＝ 実際の3着内数 ÷ 人気から見た期待3着内数**
> 1.10 なら「人気から見込まれるより1割多く馬券に絡んだ」、0.90 なら「1割少なかった」。

表中の **＊** は「2023・2024・2025・2026年の**4年とも**同じ向き（4年とも1超、または4年とも1未満）」だったことを示します。＊のない数値は年によって向きが変わるため、偶然の可能性があります。

要因の定義

| 要因 | 定義 |
|---|---|
| 走破タイム（近走指数） | 各走のタイムを「競馬場×距離×馬場状態」ごとに偏差値化（z値）。直近3走のベストをレース内で順位付け |
| 持ち時計 | データにある「最高タイム」をレース内で順位付け |
| 上がり3F | ①そのレース内の上がり順位（結果）、②前走の上がり順位（事前情報） |
| 脚質 | コーナー通過順から判定（最初のコーナーで先頭＝逃げ、最終コーナーで前35%以内＝先行、70%以内＝差し、それより後ろ＝追込）。①そのレースの脚質（結果）、②前走の脚質（事前情報）。ばんえいは対象外 |
| 体重変化 | 馬体重増減 |
| 騎手との相性 | 「騎手成績」列（＝この騎手でこの馬に乗ったときの成績）。3戦以上で3着内率50%以上を「好相性」、20%以下を「低相性」、0戦を「初コンビ」とした。あわせて、前走からの乗り替わりかどうか |
| 天候・馬場 | レース一覧の天候・馬場状態。ばんえいは馬場水分（%）を3区分 |
| 転厩・遠征 | 前走から調教師の所属地区が変わった馬＝「他地区から転入初戦」、所属地区は同じで調教師が変わった馬＝「同地区内の転厩初戦」、調教師の所属がその競馬場の地区と違う馬＝「遠征馬」 |

## 結論（全体）

1. **最も強く関係するのは人気。** 他の要因は、人気を差し引くと影響が±5〜15%程度に小さくなる。ただし、以下は**4年とも同じ向きに出ており、再現性がある**。
2. **走破タイム（近3走ベスト指数）は、人気を差し引いても残る最大の要因。** レース内1〜2位はA/E 1.05、6位以下は0.92（4年とも0.90〜0.93）。**15場すべてで、6位以下は4年とも人気以下**だった。
3. **前走の上がり3Fも効く**（前走1位1.05、6位以下0.96。4年ともほぼ同じ値）。ただし、走破タイムより影響は小さい。
4. **前走の脚質**: 前走「先行」「差し」は1.03、「逃げ」は0.96、「追込」は0.93。**前走で逃げた馬は人気になりすぎ、前走で追い込んだ馬は人気でも来ない**。4年とも同じ向き。
5. **体重**: −4〜−9kgが最良（1.03）。**+10kg以上（0.96）、+4〜+9kg（0.97）、−10kg以下（0.95）は割引**。4年とも同じ向き。
6. **騎手**: **低相性コンビは0.92**で、4年とも0.91〜0.93。好相性は1.03、初コンビは0.98。乗り替わりかどうかの差は小さい（0.99と1.01）。
7. **転厩・遠征は場によって逆になる。** 他地区からの転入初戦は、**園田0.78・名古屋0.84**で4年とも人気より走らない（2026年は園田0.64、名古屋0.75とさらに悪い）。高知0.89・門別0.87・姫路0.82も割引。遠征馬は**盛岡・笠松・金沢・浦和で1.09〜1.15**、大井・船橋・高知では割引。
8. **天候・馬場**は、4年とも同じ向きのものが少ない。比較的はっきりしているのは「**帯広は乾いた重い馬場（水分1.4%以下）で堅い**」「**大井の不良は毎年約60%が荒れる**」程度。脚質への影響では、多くの場で不良馬場ほど3着内に占める逃げ・先行の割合が上がる。
9. **オッズで補正しても、多くの要因は残る**（2026年9月・1か月分の検証）。前走逃げ（0.91）、体重+10kg以上（0.89）、好相性コンビ（1.05）は、人気順位で補正したときとほぼ同じ値だった。
10. **能力値を穴馬選びに使っても、回収率100%は超えない。ただし「消し」と「3着候補の絞り込み」には有効。** 消し条件の穴馬は、4年とも回収率が最も低い区分だった。好材料3以上の穴馬は、穴馬全体より回収率が6〜9ポイント高い（第10〜11節）。

## 10. 穴馬選びへの能力値の利用と配当面の検証

**対象**: 6番人気以下の馬（289,937頭）。再現手順は `python3 analysis/longshot_payout.py <dataディレクトリ>`（集計表は `analysis/out/ls_*.csv`）。

**好材料**: 次の5つのうち、当てはまる数を「好材料数」とした。
1. 近3走ベスト指数がレース内3位以内
2. 前走の上がり3Fが3位以内
3. 前走の脚質が先行か差し
4. 馬体重増減が−9〜+3kg
5. 低相性コンビ（3戦以上・3着内率20%以下）ではない

**消し条件**: 近3走ベスト指数がレース内6位以下で、かつ前走が追込。

**回収率の求め方**
- 単勝・複勝: 各馬に100円ずつ買った場合の回収率。
- ３連単「3着追加」: 「1着＝1〜2番人気、2着＝1〜4番人気」を軸に、3着にその穴馬を1頭加えると6点（600円）増える。この追加分の払戻の合計を、追加分の購入額で割った値。
- 誤差（標準誤差）の目安: 数万頭の区分では、単勝・３連単で±1〜4ポイント、複勝で±0.5〜1.3ポイント。数千頭の区分では±10ポイント以上になる。

| 2番人気 | 59.5% | 76% | 82% | ― |

1. **能力値で穴馬を選んでも、回収率100%は超えない。** どの区分・どの年・どの買い方でも100%を下回った。最も良い「好材料4以上の単勝（76%）」でも、1番人気の複勝（89%）に及ばない。能力値だけで穴馬券をプラスにするのは難しい。
2. **ただし、穴馬の中での「選び方」としては、はっきり効く。**

3. **的中率（A/E）の差ほどは、回収率の差は大きくない。** 好材料4以上のA/Eは1.20だが、３連単の3着追加回収率は69〜70%で、好材料3（73%）を下回る。能力値の高い穴馬は、オッズがやや低めにつく（市場もある程度は見ている）ためと考えられる（第9節）。
4. **競馬場別の回収率は誤差が大きく、判断できない。** 1場あたり数千頭では回収率の誤差が±10〜20ポイントになり、場ごとの差を読み取れない（`ls_by_course_class.csv`）。

## 11. おすすめの使い方（穴馬選び）

回収率の検証から、能力値は「儲かる穴馬を見つける道具」ではなく、**「３連単の買い目を減らすための道具」**として使うのが妥当です。

1. **消し条件で、穴馬を3着候補から外す（最も効果が確実）**
   - 「近3走指数がレース内6位以下」かつ「前走追込」の穴馬を、３連単の2・3着候補から外す。
   - 穴馬の約3分の1を外しても、取り逃す3着内の穴馬は約5分の1にとどまる。外した馬は、4年とも最も回収率が低い区分だった（3着追加で58〜64%）。
2. **3着の穴候補は「好材料3以上」から選ぶ**
   - 上位人気を1・2着に置き、3着に穴馬を加えるときは、好材料3以上の穴馬（穴馬の約4割）に絞る。これで、3着内に来る穴馬の約半分をカバーできる。
   - 追加した買い目の回収率は、穴馬全体を加える場合より6ポイントほど高い（72%と66%）。
   - 穴馬は3着に来ることが多いので（3着内に来た穴馬の50%が3着、1着は17%。場別では3着が46〜54%）、**1・2着ではなく3着に置く**。
3. **能力値は、人気薄ほど効く**
   - 10番人気以下でも、指数1〜3位の馬のA/Eは1.5〜1.7。ただし3着内率は6〜7%で、単独ではほぼ来ない。
   - ３連単の3着に「押さえ」として1〜2頭加える程度にとどめる。
4. **単勝・複勝で穴馬を買う使い方は勧めない**
   - 好材料が多い穴馬でも、単勝・複勝の回収率は70〜76%で、1〜3番人気の複勝（76〜89%）より低い。
5. **帯広（ばんえい）には使えない**
   - 上がり3F・脚質のデータがないため、好材料を数えられない。帯広では、近3走指数と体重（−10kg以下は割引）だけを参考にする。

> 注意: 回収率は、地方競馬の控除率（単勝・複勝で20%前後、３連単で25%前後）が引かれた後の値です。ここで示したのは「買い目を減らしたときに、損失をどれだけ小さくできるか」であり、プラス収支を保証するものではありません。

- **B級の「好材料3以上」の単勝が81%で最も高い**。ただし誤差は±5ポイントあり、年別では73〜97%とばらつく。
- **重賞の「消し」は特に悪い**（複勝44%、３連単の3着追加30%）。重賞では、時計が足りず前走で追い込んでいた穴馬はほぼ来ない。
- **重賞と3歳戦は、好材料3以上の穴馬を３連単の3着に加えたときの回収率が78〜80%と高め**。ただし年ごとのばらつきが大きい（重賞63〜92%、3歳67〜99%）。
- **2歳戦では、好材料による選別が効かない**（好材料3以上の単勝59%は、その他の61%と同程度）。出走歴が少なく、近走指数・前走の情報が不十分なため。新馬戦も同じ理由で、この方法は使えない。
- 競馬場×クラスまで分けると、1区分が数百頭になり、誤差が±10〜70ポイントになる（`cls_good3_by_course.csv`）。場ごとのクラス別の差は判断できない。

### クラスを踏まえた使い方

1. **B級戦では、穴馬を3着に加える価値が最も高い。** 4〜5番人気・6番人気以下とも、他クラスより回収率が5ポイント前後高い。
2. **重賞では「消し」を徹底する。** 消し条件の穴馬は、３連単の3着に加えても回収率30%で、ほぼ無駄な買い目になる。
3. **2歳戦・新馬戦では、能力値による穴馬選びは使わない。** 人気上位を中心に組む。
4. **どのクラスでも、プラス収支になる買い方は見つからなかった。** クラスの選び方で変わるのは、数ポイント程度の「損の小ささ」。

## 13. 能力値への換算（走破タイム・上がり3F・脚質・位置取り・騎手相性・距離適性）

**対象**: 2024年〜2026年9月、ばんえいを除く14場。各馬の**近5走の平均**（レース前に分かる情報のみ）から、次の6要素を作った。再現手順は `python3 analysis/ability_index.py <dataディレクトリ> [出走表horselist 出走表racelist 競馬場]`（集計表は `analysis/out/ab_*.csv`）。

| 要素 | 定義 |
|---|---|
| 平均走破タイム | 走破タイムの偏差値（競馬場×距離×馬場状態ごと、速いほどプラス）の近5走平均 |
| 平均上がり3F | 上がり3Fの偏差値（同上）の近5走平均 |
| 脚質（先行率） | 近5走で逃げ・先行だった割合 |
| 位置取り | 近5走の最終コーナー位置 ÷ 頭数 の平均（小さいほど前） |
| 騎手との相性 | この騎手でこの馬に乗ったときの3着内率（縮約）と、騎手の前年3着内率 |
| 距離適性 | 「当場・当距離の3着内率 − 全成績の3着内率」（縮約）と、近5走の平均距離からの距離変更 |

### (a) クロス分析（6要素はレース内順位などで3区分。A/Eは人気補正後）

**走破タイム × 上がり3F**（3着内率 / A/E）

| 走破タイム＼上がり3F | 1〜3位 | 4〜6位 | 7位以下 |
|---|---|---|---|
| 1〜3位 | **52.5% / 1.07** | 46.6% / 1.02 | 43.6% / 1.02 |
| 4〜6位 | 30.1% / 1.04 | 29.8% / 0.99 | 28.8% / 0.98 |
| 7位以下 | 16.9% / 0.98 | 14.8% / 0.90 | **13.0% / 0.86** |

**位置取り × 上がり3F**

| 位置取り＼上がり3F | 1〜3位 | 4〜6位 | 7位以下 |
|---|---|---|---|
| 前（〜35%） | **64.1% / 1.07** | 46.6% / 0.98 | 32.6% / 0.95 |
| 中（35〜65%） | 43.3% / 1.07 | 30.2% / 1.01 | 19.3% / 0.95 |
| 後（65%〜） | 24.6% / 1.03 | 14.4% / 0.92 | **8.0% / 0.79** |

**騎手相性 × 走破タイム**

| 騎手相性＼走破タイム | 1〜3位 | 4〜6位 | 7位以下 |
|---|---|---|---|
| 好相性 | **59.0% / 1.06** | 39.4% / 1.02 | 25.3% / 0.94 |
| 普通 | 42.5% / 1.05 | 26.5% / 1.01 | 14.2% / 0.92 |
| 低相性 | 32.1% / 1.05 | 18.1% / 0.98 | **6.8% / 0.76** |

**脚質 × 走破タイム**: 先行率が高いほど3着内率は上がる（タイム1〜3位で、先行率20%以下41% → 60%以上61%）。ただしA/Eはほぼ変わらない（1.04〜1.06）。脚質は人気にほぼ織り込まれている。

**距離適性 × 走破タイム**: 「当距離で優る」馬は3着内率が2〜3ポイント高いが、A/Eの差は0.01〜0.02とわずか。**距離変更**（近5走平均から±100m以内／100〜200m／200m超）は、ほぼ影響しなかった（`ab_cross_*.csv`）。

**クロス分析から分かること**
- **組み合わせで効くのは「上がり3F × 位置取り」**。前で運べて上がりも速い馬は3着内率64%。後方で上がりも遅い馬は8%で、人気から見込まれる値の0.79倍しか来ない。
- 上がり3Fは、走破タイムが上位の馬でさらに上積みになる（タイム1〜3位で上がり1〜3位なら1.07）。
- 騎手との相性は、**能力が劣る馬で特に効く**。走破タイム7位以下の馬が相性の悪い騎手と組むと、A/Eは0.76。
- 脚質と距離適性は、単独で見るほどは効かない（人気に織り込まれているか、他の要素と重なっている）。

### (b) 能力値への換算

6要素（＋上がり×位置の組み合わせ）を上位3着の順位ロジットに入れ、得点を**偏差値（平均50・標準偏差10）**に直した。

**要素の重み**（標準化後の係数。大きいほど能力値への寄与が大きい）

| 要素 | 係数 | 能力値への寄与 |
|---|---|---|
| 平均走破タイム | **0.78** | 最大。他の要素の合計を上回る |
| 位置取り（前ほど＋） | 0.29 | 2番目 |
| 騎手の3着内率 | 0.23 | |
| 騎手×馬のコンビ3着内率 | 0.21 | |
| 平均上がり3F | 0.12 | |
| 距離適性 | 0.04 | 小さい |
| 先行率 | 0.01 | ほぼゼロ（位置取りと重なる） |
| 距離変更・上がり×位置 | 0.00 | ほぼゼロ |

**大まかな換算の目安**: 平均走破タイムの偏差値が1標準偏差上がると、能力値は約8上がる。位置取りが前に1標準偏差（約20%）移ると約3、騎手・コンビの評価がそれぞれ1標準偏差上がると約2ずつ上がる。

| 能力値のレース内順位 | 勝率 | 3着内率 | A/E（人気補正） | 参考: 人気順の勝率 | 参考: 人気順の3着内率 |
|---|---|---|---|---|---|
| 1位 | 33.9% | 66.7% | 1.03 | 45.2% | 76.5% |
| 2位 | 20.1% | 52.9% | 1.02 | 20.9% | 59.4% |

- **能力値1位の馬は、1番人気ほどは当たらない**（勝率34%と45%）。人気は、この6要素以外の情報（調教、厩舎の勝負気配など）も含んでいる。
- **6番人気以下で能力値1〜5位の馬は、A/E 1.09〜1.13**。人気薄の中から3着候補を拾う用途では、第10〜11節の「好材料数」と同じくらい有効。
- 競馬場別に見ると、能力値1位の3着内率は60〜73%（水沢・高知・金沢が高く、浦和・名古屋・盛岡が低い）。1番人気（70〜85%）をどの場でも下回った（`ab_valid_course.csv`）。

### (d) 使い方

- 能力値は「人気の代わり」ではなく、**人気と食い違う馬を見つけるため**に使う。人気薄なのに能力値がレース内5位以内の馬は、３連単の3着候補になる。
- 近3走の**ベスト**タイム（第2節、第12節の予想モデル）と、近5走の**平均**（この能力値）で評価が分かれる馬がいる。前者は「一度速い時計を出した馬」、後者は「安定して速い馬」を高く評価する。例えば2026年10月9日の笠松12Rのペッシュプラットは、近3走ベストはレース内1位だが、近5走平均では最下位（能力値37）になる。

## 注意点

- 4年とも同じ向きでも、効果は±5〜15%程度。**人気の影響を覆すほどではなく、「人気が同じ馬の中でどれを選ぶか」の判断材料**として使うのが妥当です。
- 2026年は1〜9月分のみです。
- 「前走」「近3走」「乗り替わり」「転入」は、データ期間（2023年1月〜2026年9月）内の出走だけで判定しています。2023年初めのレースや、期間中に初めて出てきた馬は「データなし」になります。
- **2023年の船橋は、全レースの馬場状態が「良」で記録されていた**ため、馬場の分析とその年の船橋の走破タイム指数からは除きました。
- 「騎手成績」列は、その騎手がその馬に乗ったときの通算成績として扱いました（全成績との整合から判断）。
- レース中の上がり順位・脚質は**結果**であり、事前には分かりません。予想に使えるのは「前走の上がり・脚質」や「近走指数」の方です。
- 走破タイム指数は「競馬場×距離×馬場状態」で偏差値化した簡易的なもので、クラス差や斤量は補正していません。
